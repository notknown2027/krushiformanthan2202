1) PHOTOS
 - Put 5-6 photos in the photos/ folder (p1.jpg ... p6.jpg).
 - Open index.html in a text editor, find:  const PHOTOS=[];
   Change to: const PHOTOS=["photos/p1.jpg","photos/p2.jpg","photos/p3.jpg","photos/p4.jpg","photos/p5.jpg","photos/p6.jpg"];
 - Captions: edit the CAP array just below it.

2) PUBLISH ONLINE (free)
 - Netlify Drop: go to app.netlify.com/drop and drag the whole folder in. You get a link to share.
 - Or GitHub Pages: upload the files to a repo, then Settings > Pages.
 - Test on your phone before sending.

Tip: keep photos under ~500 KB each for fast loading.
